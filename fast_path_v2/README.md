# Experimental fast executor

This is a **deterministic** alternative to the failed free-text role prompts.
No foundation model runs on its tick request path. Five independent role instances
can parse the same state; there is no central orchestrator or hidden network call.
This does not establish tournament eligibility, match strength, or<=10ms AWS latency.

Explicit possession permits a short clear shot or safe pass; unknown possession
returns control to built-in AI. One eligible nearest outfielder presses. Other
roles cover the middle, keep a link and preserve an attacking outlet. No RESET,
SLIDE_TACKLE, guessed MOVE_TO, tools, memory writes or per-request Bedrock calls.

Known limitations: the inherited small-field X/Z adapter uses goalkeeper anchors
as goal proxies. Exact goalposts, shot physics and pass range are not surveyed.
Unknown frames release to the engine; the engine can then shoot itself. Opponent
corner runs are addressed only by central coverage, not demonstrated man-marking
of the user's observed goal. The code is a hypothesis, not an immunity guarantee.

`python3 -m unittest tests.test_fast_path_v2` checks ownership, old context,
malformed inputs, single presser, unknown frame and bounded session isolation.
`python3 -m fast_path_v2.evaluate` records synthetic checks and CPU timings.
Only a separate FWD2 pilot may be used for native timing initially. Never replace
all five slots from local timing results. Preserve original M8 rollback and require
actual native command validation, fresh portal Fitness and an isolated Practice.
