# Deep run: что пробовать после анализа latency и тактики — 26 октября 2026

Цель: выбрать изменения, которые могут повысить шанс в турнире, не увеличивая критический путь решения.

## Решение

### Пробовать сейчас

1. **L02B как Setup A.** Это уже подготовленная попытка уменьшить startup/transport стоимость model-free MID без изменения его L01 football policy. Она полезна как инженерный контроль. Главный риск — прошлые L02/V1/V2 уже проваливали first-call deadline, поэтому L02B имеет право на матч только после нового native PASS.

2. **M11 Hybrid Fast MID как Setup B.** Убрать LLM у MID, оставить остальные роли и 1-1-2 неизменными. MID получает bounded FastEngine policy: possession safety, close clear shot, safe outlet, single local press, central cover, keep shape. Это лучший следующий тест, потому что изменение одно, rollback точный, а latency и football effect можно измерить отдельно.

3. **First/later session split.** Считать не average latency, а отдельно fresh-session first calls, later calls, p50/p95/max и late share. Multi-second first call уже наблюдался без модели, поэтому это обязательный gate обоих кандидатов.

4. **HOME/AWAY cases в native plan.** AWAY остаётся крупным риском. Новый screen обязан содержать обе стороны и строгий player2 contract.

### Не пробовать в том же блоке

1. **Большой новый Elastic Counter prompt.** Тактическая идея полезна, но добавлять её текстом во все роли сейчас плохо: увеличивает контекст, усложняет причинность и не решает Runtime latency. Переносить отдельные invariants в код позже.

2. **Новая foundation model для FWD1/GK/DEF.** Nova 2 Lite остаётся лучшим проверенным компромиссом. Haiku/Sonnet были существенно медленнее; Micro быстрее в узком selector, но качество/полный Harness не доказаны. Не смешивать model switch с MID A/B.

3. **Одновременно deterministic DEF + MID + FWD2.** Потенциально это правильное конечное направление, но это слишком большая поверхность изменения. Если M11 проходит, следующий кандидат может отдельно убрать LLM у DEF.

4. **Формация 1-2-1.** Исторически выглядит жизнеспособно, но текущая 1-1-2 имеет более сильную и воспроизводимую базу. Formation experiment — отдельный будущий блок.

5. **Новый FWD1 prompt/P01.** P01 уже провалил paired screening, а selective-autonomy prompt-only варианты ошибались на AWAY. Не возвращать их без новой причины.

6. **All-deterministic five-player rewrite.** Слишком высокий риск: GK/FWD1 требуют более тонкой обработки, а качество deterministic policy для них не доказано реальными сериями.

## Архитектура, к которой стоит идти после турнира

State parsing и identity -> deterministic safety/geometry -> obvious action fast path -> LLM только для genuinely ambiguous choice -> strict serialization.

То есть модель должна выбирать из небольшого набора допустимых действий, а не заново интерпретировать весь футбол каждый тик. Но текущий M11 намеренно делает только один шаг в эту сторону: MID.

## Что должно заставить нас отказаться от M11

- любой wrong-player/wrong-side;
- fresh-session first-call deadline miss;
- native p95 вне gate;
- Fitness <5/5;
- исчезновение атакующих действий или рост scoreless games;
- центральная защита явно хуже;
- преимущество существует только в локальном CPU timing, а full-response path не ускорился.

## Что будет сильным положительным сигналом

- zero invalid/incomplete native replies;
- заметно меньший late share и стабильный later-call p95;
- не хуже baseline по shots-on-target и goals;
- нет нового HOME/AWAY перекоса;
- пять игр дают приемлемую устойчивость без ручных правок между матчами.

Вывод: завтра логично тестировать не «самую умную» новую команду, а два разных способа сделать одну роль быстрой. Это максимизирует информацию на единицу риска.
