До каждого deployment/match: idle (не LIVE/PREPARING), нет конкурирующего
probe, exact configuration и rollback сохранены, workshop/quota проверены.
Между играми только сохранение результата и проверка неизменности состава.
Недоступные метрики — null. Portal average не заменяет полный invoke timing.

Результат каждой серии должен включать WDL/PPG/GF:GA/GD, shots/SOT,
scoreless/clean sheets, HOME/AWAY, first HTTP/valid/competitive PLAY_ON,
p50/p95/max, late/invalid, candidate commands/reasons/model calls,
точную дельту таблицы и ограничения телеметрии. Приватные ARN, credentials,
состояния и снимки остаются в игнорируемой `.local/stage2-20261027/`.

Решение принимает обязательную надёжность прежде результата; смешанные
данные означают сохранение Baseline. Финальный ответ выбирает ровно один
из PROMOTE BASELINE / PROMOTE L02B / PROMOTE M11 V3 /
EVIDENCE INSUFFICIENT — KEEP BASELINE.
